# Mini projeto de saldo

Projeto de terminal feito para praticar lógica com JavaScript. Ele permite consultar um saldo inicial, transferir dinheiro, depositar dinheiro e sair pelo menu.

## Requisitos

- Node.js instalado
- Dependência `chalk` instalada no projeto

## Como executar

Na pasta raiz do projeto, rode:

```bash
node testandokakaka/neymar.js
```

O menu aparece novamente depois de cada operação. Escolha `4` para encerrar.

## O que dá para praticar

- Variáveis e atualização de valores
- Entrada de dados pelo terminal com `readline`
- Condições com `if` e `else`
- Repetição com `while`
- Validação de números e valores positivos
- Cores no terminal com `chalk`

O saldo começa em `R$ 500` e existe apenas enquanto o programa está rodando. Ao iniciar de novo, ele volta ao valor inicial.
